# 《薪火·湘征》—— 长征湖南段交互数字展（v1）

> 码承长征薪火，页绘青春征途 · 纪念中国工农红军长征胜利90周年（1936—2026）
> 湖南工学院（衡阳）网页设计大赛参赛作品

纯静态网页，无需构建工具，**完全离线可运行**（所有第三方库和地图数据都在本地）。

---

## 一、如何运行

页面使用了 ES Module 和 `fetch` 读取地图数据，浏览器出于安全限制**不能直接双击 index.html 打开**（file:// 协议下会报跨域错误），需要起一个本地服务器：

| 系统 | 方法 |
|---|---|
| Windows | 双击 `start.bat`（需已安装 Python 3），自动打开浏览器 |
| macOS / Linux | 终端运行 `./start.sh`，再访问 http://localhost:8000 |
| 任意 | 在本目录运行 `python -m http.server 8000`；或用 VS Code 的 Live Server 插件 |

推荐浏览器：Chrome / Edge 最新版。比赛现场无网络也能正常演示。

**部署到 GitHub Pages**：整个目录原样上传即可（访问地址形如 `https://<用户名>.github.io/xinhuo-xiangzheng/`）。
全站**只用相对路径**（没有任何以 `/` 开头的路径），所以既能在 `localhost:8000/` 根目录运行，也能在 `/xinhuo-xiangzheng/` 子路径下运行（v1 已用“以上级目录为根”的服务器实测）。

## 三、页面内容（v1）

1. **首页「启程」**：报纸刊头 + 大标题；向下滚动时红色行军线自东向西画出，地名依次浮现。
2. **湘征地图（核心）**：左图右文的滚动叙事；地图飞行、涟漪点、流光路线；通道转兵“北上 / 西进”岔路口互动。
   - v1：四个节点卡片下方有 **“查看详情 →”**，进入详情页。
   - v1：地图右上角 **「▶ 自动播放」**，现场演示时自动一站站往下走（每站约 6.5 秒）；**空格**暂停/继续，**← / →** 切换上一站/下一站；用户自己滚动时自动暂停；到尾声自动停止。
3. **节点详情页（第三层，v1）**：`pages/rucheng|xiangjiang|tongdao|sangzhi.html`
   - 面包屑 → 页头（站次、日期、标题、地点）→ 历史经过（首字下沉）+ 时间轴 → 位置小地图（含“衡阳”参照点）+ 人物小卡 → 红底金句 → 今天的它（纪念馆/旧址简介 + 从衡阳出发怎么去）→ 上一站 / 回到湘征地图 / 下一站。
   - “回到湘征地图”会带 `#step-xxx` 返回首页并定位到对应卡片。
4. **薪火问答（#qa，v1）**：AI 讲解员「小红」，电报单样式对话（去电 / 来电、流水号、方格稿纸、“薪火电报局”落款），三个预设问题、打字机效果、匹配度显示、推荐追问；可选大模型模式。
5. **青春接力（#relay，v1）**：填写昵称、专业/班级、“新长征”目标（≤40 字）→ 实时预览并生成 1080×1440 海报 → 下载 PNG；接力墙卡片带编号，计数器“已有 N 位同学接力”滚动入场；8 条示例数据盖“示例”章，可一键清除。
6. **关于我们（#about，v1）**：队名「待定」、设计理念、技术栈、史料来源（待登记）、参考项目。

## 三点五、各技术点怎么实现（答辩 Q&A 备查）

### 1. 小红是怎么“听懂”问题的？（`js/qa-engine.js`）
- **为什么不用分词词典**：中文没有空格。我们用**二元分词（bigram）**：“通道转兵”→「通道」「道转」「转兵」，不需要词典，对“刘家坪”“陈树湘”这类专有名词同样有效；另保留单字（权重 0.5）照顾“贺龙”这种两字问题。
- **先去虚词**：“什么、怎么、吗、的……”这类词每个问题都有，先去掉。
- **TF-IDF**：TF=词在这条资料里出现的次数；IDF=log((N+1)/(含该词条数+1))+1。“沙洲”只在少数条目出现 → 权重高；“红军”到处都有 → 权重低。每条资料的文本 = 问题 + 同义问法（权重 1）+ 答案（权重 0.3）。
- **余弦相似度**：问题与每条资料都变成向量，cos = 点积 / (长度×长度)，取最高的那条。
- **兜底**：最高分 < 0.22，或问题较长但**覆盖率**（问题里的二元组有多少是知识库认识的）< 30%，就回答“这个问题小红还要再学习…”，并推荐 3 个相关问题。覆盖率这一步专门防止“推荐一家衡阳的餐厅”因为“衡阳”二字误命中。
- **可测试**：引擎是纯函数、不碰页面，`node tests/qa-engine.test.mjs` 一键自测（自检索 52/52 + 常见问法 + 无关问题兜底）。
- **为什么不直接上大模型**：比赛现场可能没网；大模型可能“编历史”。本地检索保底、答案全部来自我们核对过的知识库。

### 2. 大模型模式（RAG）怎么做的？（`js/qa.js`）
- 默认关闭。打开“⚙ 大模型设置”，填兼容 OpenAI 的 Base URL、Key、模型名（如 DeepSeek、通义千问的兼容接口），**只存在本机 localStorage**。
- 提问时：先用本地引擎检索 **top-3** 条资料 → 放进系统提示词的【资料】里 → 提示词要求“只能依据资料回答，资料没有就说还要再学习，≤150 字” → POST `/chat/completions`。这就是**检索增强生成（RAG）**。
- 20 秒超时（AbortController）；失败自动退回本地模式并注明原因，演示不卡死。
- 安全提醒：纯前端调用意味着密钥对使用这台电脑的人可见，所以只建议在自己电脑上演示；正式上线应改为后端代理转发。

### 3. 打字机效果
- 用 `setTimeout` 逐字写入 `textContent`，标点后停顿稍长（110ms vs 32ms），末尾闪烁光标（CSS `::after` + `steps(1)` 动画）。系统开启“减少动态效果”时直接显示全文。

### 4. 接力海报怎么生成的？（`js/relay.js`）
- 没用 html2canvas，**直接用 Canvas 2D API 画**：纸色底 + 9000 个随机噪点（固定种子，同一编号每次一样）+ 径向暗角 → 双线外框 → 分段着色的《薪火·湘征》→ 红色横幅 → 量出数字宽度后居中排布“第 0009 位接力者” → 逐字测量宽度自动换行的目标 → 贝塞尔曲线行军线（汝城→湘江→通道→桑植→1936→我）→ 日期、口号、“湘”字印章。
- 下载：`canvas.toDataURL('image/png')` 得到图片数据 → 临时 `<a download="薪火湘征-接力海报-0009.png">` 触发下载。
- 边输入边预览（每次 input 重画），提交后才能下载。

### 5. 接力墙的数据存哪？能换成云端吗？（`js/relay-store.js`）
- **适配器模式**：界面只调用 `store.list()` / `store.add()`（都返回 Promise）。现在实现是 localStorage；文件末尾有 **Supabase** 的注释示例（REST 接口 + RLS 行级安全 + 数据库 check 约束限制长度），LeanCloud 同理。换后端只改一行，界面代码不动。
- 编号 = 当前最大编号 + 1，清除示例后也不会重号。示例数据带 `sample: true`，清除后用标记位保证不再重新写入。

### 6. 防 XSS（评委常问）
- 用户输入**从不当作 HTML**：写进页面一律用 `textContent`（浏览器只当纯文本），画进海报用 `fillText`。输入 `<img src=x onerror=alert(1)>` 只会原样显示成文字（v1 已用自动化测试验证：接力墙中 img/script 元素数为 0）。
- 配置文件里的文案在拼接 HTML 时也统一经过 `esc()` 转义。
- 输入清洗：去掉控制字符和零宽字符、合并空白；长度按“字符”计算（`[...str].length`，emoji 也算 1 个）；HTML `maxlength` + JS 二次校验；5 秒提交节流。
- 提醒：前端校验能被绕过，接入云端后必须在服务端再做一次长度/内容校验（示例里已写明）。

### 7. 自动播放（`js/autoplay.js`）
- 不另写一套动画：只是**自动把页面滚到下一张卡片**，卡片越过触发线后 scrollama 照常触发地图飞行——与手动滚动走同一条代码路径，不会出现两套状态不一致。
- 键盘：只有地图栏目在屏幕中部时才接管 ←/→ 和空格；在输入框、对话框里不接管；焦点在按钮上时空格交给按钮自己（避免一次按键触发两次）。
- 用户滚轮/触摸 → 自动暂停，把控制权还给人。

### 8. 详情页为什么四个 HTML 内容一样？（`js/detail.js`）
- **模板 + 数据**：四个页面只差 `<body data-node="tongdao">`；`detail.js` 读这个 id，从 `nodes.js` 的 `details` 取内容渲染整页，上一站/下一站按 `detailOrder` 自动算出。加一个节点 = 在 nodes.js 写内容 + 复制一个 HTML 改 data-node。
- 为什么不用一个 `detail.html?id=tongdao`：独立文件名对分享、收藏、搜索引擎更友好，也能在不支持查询参数的场景直接打开。

### 9. 相对路径 & 子路径部署
- 首页引用 `css/…`、`js/…`、`data/…`；详情页引用 `../css/…`、`../js/…`；`fetch('js/data/kb.json')` 等全部相对当前页面。没有以 `/` 开头的路径，所以 GitHub Pages 的 `/xinhuo-xiangzheng/` 子路径和本地根目录都能用。

## 四、技术选型与理由（答辩可用）

| 需求 | 选择 | 理由 |
|---|---|---|
| 滚动驱动动画 | **GSAP + ScrollTrigger** | 业界标准；`scrub` 把滚动进度直接绑定到动画进度，画线效果 60fps 流畅 |
| 画线原理 | SVG `stroke-dasharray` + `stroke-dashoffset` | 把描边设成“一段实线+一段等长空白”，再改变偏移量，实线就像被一笔画出来 |
| 地图 | **Apache ECharts 5**（geo + lines + effectScatter） | 国产开源、中文文档完善；原生支持 GeoJSON、迁徙线流光、涟漪散点 |
| 地图“飞行” | GSAP 补间一个 `{经度, 纬度, 缩放}` 对象，每帧 `setOption` | 比直接跳转更平滑，且可控制缓动曲线 |
| 滚动叙事触发 | **scrollama** | 基于 IntersectionObserver，比监听 scroll 事件更省性能；只负责“哪一步进入屏幕” |
| 内容组织 | 章节配置数组（`js/data/nodes.js`） | 借鉴 mapbox/storytelling：内容与逻辑分离，非程序员队友也能改文案 |
| 字体 | 系统中文衬线/无衬线字体栈 | 不依赖网络字体，离线可用、加载快 |
| 纸张质感 | CSS 内联 SVG `feTurbulence` 噪点 + 径向渐变暗角 | 无图片文件、体积极小 |
| 无障碍 | `prefers-reduced-motion`、`aria-live`、键盘焦点样式 | 系统开启“减少动态效果”时：行军线直接完整显示、地图不飞行、无涟漪 |
| 响应式 | CSS Grid + 媒体查询 | 桌面左右分栏；手机端地图吸附在上方、卡片在下方滚过 |
| 问答检索（v1） | 二元分词 + TF-IDF + 余弦相似度 | 无需词典和后端，几十 KB 代码，离线即可运行，可解释（界面显示匹配度） |
| 大模型（v1，可选） | OpenAI 兼容接口 + RAG | 兼容国内多家模型；只给 top-3 资料，限制“编历史” |
| 海报（v1） | Canvas 2D 直接绘制 | 比 html2canvas 更可控、无额外依赖，导出清晰的 1080×1440 PNG |
| 接力存储（v1） | localStorage + 适配器 | 零后端即可演示；接口统一，后续可无缝换成 Supabase / LeanCloud |

为什么用经典 `<script>` 加载库、用 `type="module"` 写自己的代码？库的 UMD 版本直接挂到 `window`，无需打包；我们自己的代码按功能拆成模块，用 `import/export` 组织，结构清楚。
